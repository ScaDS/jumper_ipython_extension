# Script Writer

`jumper_extension.adapters.script_writer` converts recorded cells into a Python
script and handles IPython magic commands (commands prefixed with `%` or `%%`).
See [Architecture](architecture.md) for the transformation flow and the
[Jupyter API](../../../api/jupyter.md) for notebook entry points. The application
programming interface (API) listings below are generated from Python source.
